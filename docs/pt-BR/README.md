# Traduções pt-BR — Copilot for Obsidian

## Português (pt-BR)

Traduções não oficiais, para o português do Brasil, das skills embutidas no plugin Copilot (`logancyang/obsidian-copilot`). Este fork é mantido por **Roger Luft (veilwaker)**.

As embutidas não podem ser editadas, então cada tradução é uma **skill separada, instalável**, que fica **ao lado** da original:

1. Copie `skills/<nome>-ptbr/` para `<pasta do Copilot>/skills/` no seu vault (o padrão é `copilot/skills/`).
2. Em **Settings → Copilot → Skills → Your skills**, ative a skill para cada agente (OpenCode, Claude, Codex).

- Índice gerado automaticamente pelo workflow [`.github/workflows/ptbr-index.yml`](../../.github/workflows/ptbr-index.yml). Toda segunda-feira ele confere no upstream se os arquivos de origem mudaram e, se mudaram, abre um PR marcando as traduções desatualizadas e pede revisão do `@jules` antes do merge.
- Licença e atribuição: [NOTICE.md](NOTICE.md).
- Histórico: [CHANGELOG.md](CHANGELOG.md) · Instruções para agentes: [AGENTS.md](AGENTS.md).

## English

Unofficial Brazilian Portuguese versions of the Copilot plugin's built-in skills (`logancyang/obsidian-copilot`). This fork is maintained by **Roger Luft (veilwaker)**. Built-in skills can't be edited, so each translation is a separate, installable skill that sits alongside the original. To install one, copy `skills/<name>-ptbr/` into `<Copilot folder>/skills/` (by default `copilot/skills/`) and enable it under **Settings → Copilot → Skills**.

A weekly workflow (`.github/workflows/ptbr-index.yml`) compares each source file with the upstream commit it was translated from, updates the index above, and opens a PR asking `@jules` to review before merging. License and attribution: [NOTICE.md](NOTICE.md).
